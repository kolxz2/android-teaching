### СЛАЙД 15 — JDK и JVM

**Заголовок:** Зачем здесь JDK и JVM

**Текст на слайде:**

- **JDK** (Java Development Kit) — компилятор и инструменты для JVM-языков
- **JVM** (Java Virtual Machine) — виртуальная машина, которая исполняет байткод
- Kotlin компилируется в байткод, совместимый с Java
- Android Studio ставит нужный JDK сама — отдельно «искать Java» обычно не нужно
- На устройстве код выполняется уже не классической JVM, а в среде Android (ART)

**Визуал:** цепочка: `Kotlin-код → компилятор → байткод → ART на устройстве`.

**Заметки спикера:** Студенты часто путают «Java как язык» и «Java как платформа». Мы пишем на Kotlin, но стоим на JVM-стеке. ART (Android Runtime) — преемник Dalvik, исполняет приложение на телефоне.

### СЛАЙД 23 — Кто запускает приложение

### СЛАЙД 47 — push и pull

**Заголовок:** push отправляет, pull забирает

**Текст на слайде:**

```
git push -u origin main
git push -u origin lecture-01
git pull
```

- `push` — отдать свои коммиты
- `pull` — взять чужие (и слияния с GitHub)
- `-u` (upstream) — запомнить связь ветки с remote, дальше достаточно `git push`
- Нет push — преподаватель вашего кода не видит

**Визуал:** стрелка вверх Push, стрелка вниз Pull.

**Заметки спикера:** «У меня всё работает локально» — не сдача. Сдача = видно на GitHub. Если push отклонён: сначала pull, не force (force на курсе запрещён без отдельного разрешения).
