# Лекция 06. Основы вёрстки на Jetpack Compose

**Блок:** Основы Android
**Основная часть:** 60 минут объяснения с живым кодом
**Если занятие длится 90 минут:** после основной части проведите 30 минут практики
**Проект:** FinanceApp, локальная ветка `lecture-06`
**Материал для лектора:** [lecturer-guide.md](lecturer-guide.md)

## Цель

Научить студентов собирать экран Compose из базовых контейнеров, понимать ограничения и порядок модификаторов, переиспользовать компоненты и связывать ввод с состоянием. Лекция опирается на реальный код FinanceApp, подготовленный в ветке `lecture-06` от `master`.

## Перед занятием

1. Откройте FinanceApp на ветке `lecture-06` и запустите модуль `app` на эмуляторе.
2. Откройте файлы `MainActivity.kt`, `Lecture06Screen.kt`, `LayoutExamples.kt`, `FinanceExamples.kt`, `InputExamples.kt`.
3. В презентации нажмите кнопку панели лектора: на каждом слайде есть расширенная теория, подсказка для демонстрации и ссылки на официальные источники.
4. Проверьте форму: расход 500 ₽ даёт прогноз 24 500 ₽, кешбэк — 24 550 ₽, доход отключает кешбэк; добавление обновляет локальный учебный баланс.

## Основная часть: 60 минут

### 0–10 минут. Декларативный UI и структура проекта

- 0–3: показать результат занятия и весь экран приложения.
- 3–6: разобрать `setContent { MaterialTheme { Lecture06Screen() } }`.
- 6–10: пройти по дереву `Surface → LazyColumn → секции`. Поменять порядок двух `item` и вернуть.

Ключевой тезис: composable-функция описывает UI для текущих данных. Рекомпозиция может перезапустить лишь нужные части дерева, поэтому тело composable должно оставаться быстрым и без побочных эффектов.

### 10–25 минут. `Column`, `Row`, `Box`

- 10–15: `Column` и `Arrangement.spacedBy` — порядок и расстояния.
- 15–20: `Row`, `verticalAlignment`, два `weight`; заменить 2:1 на 1:1 и вернуть.
- 20–25: `Box`, `align`, два слоя; переместить надпись из `TopEnd` в `BottomEnd`.

Спросите аудиторию, какой контейнер выбрать для строки операции, карточки баланса и бейджа поверх аватара. Попросите объяснить главную и поперечную оси у `Row` и `Column`.

### 25–37 минут. Размеры, `Modifier` и системные области

- 25–30: найти в коде `fillMaxWidth`, `height`, `size`, `padding`, `background`, `clip`.
- 30–34: сравнить две цепочки `background().padding()` и `padding().background()` на экране.
- 34–37: объяснить `dp`, ограничения родителя и `windowInsetsPadding(WindowInsets.safeDrawing)`.

Проверка понимания: студенты должны предсказать, где будет цветной фон после перестановки модификаторов. Напомните, что `enableEdgeToEdge()` в Activity делает обработку системных областей видимой задачей интерфейса.

### 37–49 минут. Компоненты и список

- 37–41: открыть `BalanceCard`, объяснить композицию `Card + Column + Text` и типографику темы.
- 41–44: открыть `TransactionRow`, изменить стиль суммы и увидеть изменение всех строк.
- 44–47: проследить путь `transactions → items → TransactionRow`; посчитать элементы, обсудить `item` и `key`.
- 47–49: сопоставить обязанности `LazyColumn` и `RecyclerView`; затем добавить четвёртую операцию.

Уточните, что `key = { it.title }` достаточно только для текущего учебного набора с уникальными названиями. Для реальных операций нужен устойчивый ID.

### 49–55 минут. Состояние и ввод

- 49–51: разобрать `rememberSaveable`, `value` и `onValueChange` поля ввода.
- 51–53: переключить Checkbox, Switch, FilterChip и Slider; проследить общий прогноз и зависимость доступности кешбэка от типа операции.
- 53–55: нажать «Добавить операцию»; сравнить производный прогноз с локальным балансом после фиксации и объяснить разницу с сохранением в репозиторий.

### 55–60 минут. Мини-практика и итог

Дайте студентам 3 минуты на два изменения: четвёртая операция и веса плиток 1:1. Оставшиеся 2 минуты — показать результат и повторить пять идей: контейнер, Modifier, компонент, список, состояние.

## Дополнительные 30 минут для пары на 90 минут

1. **10 минут:** передать баланс в `BalanceCard(balance: String)` параметром; обсудить повторное использование и тестируемость.
2. **10 минут:** добавить `id` в `SampleTransaction`, использовать его как ключ и создать две операции с одинаковым названием.
3. **10 минут:** проверить узкий экран, альбомную ориентацию и крупный системный шрифт; предложить улучшения отступов и переносов текста.

## Домашнее задание

Сверстать карточку финансовой цели и список из четырёх операций. Использовать минимум один `Row`, один `Column`, один `Box`, две осмысленные цепочки `Modifier` и переиспользуемый composable для строки. В README кратко объяснить, где хранится состояние и почему для списка выбран устойчивый ключ. Сдать через PR из отдельной ветки.
